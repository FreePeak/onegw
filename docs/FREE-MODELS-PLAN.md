## Scope decisions (operator's, 2026-09-16)

1. **Literal full parity** — every free-model capability in either upstream is
   ported, including the token-headline statistics, deposit-boost accounting,
   free-provider rankings and the Radar feed overlay.
2. **Live-only, no static table** — **no vendored free-tier research table.**
   OmniRoute's `open-sse/config/freeModelCatalog.data.ts` is ~462 hand-curated
   records generated by a "50-agent web research + adversarial verification"
   pass, marked *do not edit by hand*. onegw does not copy it and does not
   re-implement the research pass. Every free model, budget, context window and
   price is **derived at runtime** from (a) upstream `/models` bodies
   (OpenRouter-shaped rows carry `pricing.prompt/completion` and
   `context_length`), (b) the models.dev catalog, (c) signed upstream
   `x-ratelimit-*` response headers, (d) vendor quota endpoints, (e) the
   operator's TOML. Consequence, stated plainly: **one headline number
   ("~1.51B documented free tokens/month") is not reproducible without curated
   data.** It is reproduced as *measured* free capacity for the providers this
   instance actually has credentials for, which is the number that means
   something to a self-hosted gateway — and it is computed with the same
   pool-deduped math so it cannot inflate the way the upstream comments warn
   about (§Phase 6, Aggregation).

## What "free" means upstream (the part that must agree everywhere)

Both upstreams implement the *same* three-clause predicate; onegw needs exactly
one owner of it too, or the list, the router and the quota disagree — which is
OmniRoute pitfall #10 ("filtering listing without filtering routing = 402/403",
`open-sse/services/autoCombo/paidModelFilter.ts:1-13`).

| Clause | Source |
| --- | --- |
| id ends `:free` (or the reseller's `-free` / `/free` spelling) | `OmniRoute/src/shared/utils/freeModels.ts:57-70`; `9router/open-sse/providers/capabilities.js:384-389` (free variant matched **before** the paid base id, because free tiers cap context/output well below the paid window) |
| `pricing.prompt == 0 && pricing.completion == 0` | `freeModels.ts:44-49,58-62`; `9router/src/app/api/providers/suggested-models/filters.js:8-17` (plus a `context_length >= 200000` utility floor so a useless free model is never advertised) |
| membership in a known free set for the (alias-resolved) provider | `freeModels.ts:22-33,61-66` — onegw's equivalent is the live catalog, not a table |

Plus two upstream rules that are easy to miss:

* **Provider gate**: `providerHasFreeModels(p)` false ⇒ *all* of p's models hide
  under `hidePaidModels` (`freeModels.ts:18-20`, `catalog.ts:262-267`). Without
  it, a provider with no free lane leaks its whole catalog into a free-only view.
* **Dead-id quarantine**: a delisted free id is kept as a `discontinued`
  tombstone so it is recognized but never summed
  (`freeModelCatalog.data.ts:332-343`); 9router keeps a one-line
  `DEAD_FREE_OPENCODE_MODELS` set for the same reason (`filters.js:4`).

## Phase 1 — the free index and its data sources

**Goal:** one package answers "is this model free, what is its window, what
does it cost" from live evidence. No routing behavior changes yet.

**New `internal/free/free.go` (~250 LOC + tests)**

```go
type Entry struct {
    Provider string  // onegw provider name (alias-resolved)
    Model    string  // upstream id, verbatim (":free" suffix kept)
    Free     bool
    Source   string  // "suffix" | "pricing" | "catalog" | "config" | "radar" | "probe"
    Context  int     // tokens; 0 = unknown
    MaxOut   int
    InputPrice, OutputPrice float64 // USD / 1K; -1 = unknown
    Keyless  bool    // served with no credential
    PoolKey  string  // shared-quota pool; "" = model counts alone
    FreeType string  // recurring-daily | recurring-monthly | recurring-credit |
                     // recurring-uncapped | one-time-initial | keyless | discontinued
    Note     string  // vendor's own words; "discontinued" tombstone reason
    At       time.Time
}

type Index struct { /* RWMutex + map[prov][model]Entry + per-provider gate */ }

// Free reports the three-clause predicate. The ONLY owner of it; server,
// router, quota and dashboard all call here (upstream pitfall #10).
func (ix *Index) Free(prov, model string) bool
func (ix *Index) ProviderHasFree(prov string) bool
func (ix *Index) Upsert(e Entry)          // additive-only, see Rule below
func (ix *Index) Rows(prov string) []Entry
func ParseModelList(body []byte) []Entry   // OpenRouter-shaped {data:[...]}
func IsFreeID(model string) bool            // ":free" | "-free" | "/free" tail
func ContextFloor() int                     // 200_000, from 9router filters.js:14
```

* `ParseModelList` tolerates the three shapes the upstreams emit:
  `{data:[{id,context_length,pricing:{prompt,completion}}]}` (OpenRouter/Kilo),
  `{models|data:[{id}]}` (plain OpenAI), `{data:[{name,context_window}]}`
  (models.dev). Unknown → empty, never an error (9router `route.js:24-33`:
  every failure path answers `{data: []}`).
* **Additive-only rule**: a parsed row never *downgrades* a hand-written
  `[[providers.tier]]` declaration — static config always wins
  (9router `sync.js:122-135`, `catalogOverride.js:48-60`). Enforced in
  `Upsert`, tested.
* Free variant matched **before** the paid base id, so a `:free` id gets the
  free tier's smaller context (9router `capabilities.js:384-389`).

**New `internal/free/sync.go` (~140 LOC) — models.dev + OpenRouter periodic sync**

9router's loop ported 1:1 (`src/lib/modelCatalog/sync.js`): 60s startup delay,
24h interval, 30min retry-on-failure, 60s timeout, `MODEL_CATALOG_SYNC=off`
equivalent, ETag conditional GET with the etag re-read from the artifact after
restart (`sync.js:222-231`), two atomic artifacts (tmp+rename) under `data_dir`:
`free-catalog.json` (deltas) + `free-catalog-raw.json`. In-memory copy
invalidated by mtime, hot path = one `stat` (`catalogOverride.js:1-6,27-46`).
The "two layers" rule survives: modality is decided by provider **majority vote**
(one vote per provider per normalized base id, `MIN_SHARE=0.5`), limits are
provider+model keyed because gateways truncate differently.
Normalization: `zai-org/GLM-4.6V:free` → `glm-4.6v` (`sync.js:51-54`),
`(\d)-(\d)` → `$1.$2` id version fix.

**EXTEND `internal/server/admin_models.go`** (present at this base): the
discovery cache keeps `[]free.Entry`, not `[]string`, and the auto pass feeds
`Index`. Keep `discoveredModels{IDs,...}` JSON shape for the existing page and
add `Rows` beside it — the cache is a Server field, so a SIGHUP does not throw
away a catalog the operator is looking at (`admin_models.go:19-22` rationale).

**Config** (`internal/config/config.go`, `[free]` table + env `ONEGW_FREE_*`):

```toml
[free]
# hide_paid_models strips every non-free model from /v1/models and from
```

## Phase 2 — advertising and visibility

**Goal:** what a client sees through `/v1/models` matches what the gateway will
route, and free lanes are findable.

* `[free] hide_auto_combos = false` (default) drops every synthesized `auto*`
  id from `/v1/models` — the port of OmniRoute's `settings.hideAutoCombos`
  (`catalog.ts:259-261`): keeps a virtual combo out of a client's model picker
  without touching routing.

* `handleModels`: gate on `free.Index` (and `ProviderHasFree`); annotate
  `{"id": "...", "free": true, "display_name": "… (free)", "context_length": N,
  "owned_by": "onegw"}` — extra keys, `object:"model"` unchanged, so OpenAI
  clients ignore them. Free-first stable sort per provider
  (`freeModels.ts:87-97` `sortModelsFirstFree`).
* Dashboard Models page: a free chip + a "show only free" filter, and
  `POST /admin/config/providers/{name}/models/fetch {"apply":true,"free_only":true}`
  writing only free ids into `models`, returning `free_filter_empty` when the
  fetch found rows but none were free (`freeModels.ts:103-114`). A save whose
  `models` list matches only paid ids is **rejected** under `hide_paid_models`
  (`matchesOnlyPaidModels`, `freeModels.ts:149-165`).
* Usage cost side: a `:free` model with no pricing row bills $0 rather than
  inheriting a fallback rate (OmniRoute `usage/analytics/route.ts:219-220`).
* `hide_paid_models` also removes paid-tier virtual ids from the catalog rather
  than merely hiding them (`isPaidTierAutoId`, `builtinCatalog.ts:108-114`) —
  same rule as #14 below, one predicate.

**Tests:** server-level `httptest` matrix (free/paid × hide on/off × provider
with/without a documented lane) + a dashboard template render test.

**Commit:** `feat(free): free-only advertising + import filter on /v1/models`

## Phase 3 — free-lane quota windows

**Goal:** OpenRouter-class lanes stop burning doomed attempts, from upstream
truth rather than a table.

**EXTEND `internal/quota`** rather than adding a parallel tracker: its key
becomes `(provider, lane)`, where `lane` is `"free"` for a model the index says
is free and `""` otherwise. All of the existing machinery —
`currentWindow`/`gridStart`/`isoWeekStart`/`monthGrid` reset grids, `roll`,
`exhausted`, park-until-reset, `Inherit` on reload, `quota_state` persistence —
applies unchanged to the free lane. Callers pass the lane in one place:
`Def.Do` already resolves provider+model.

* Attempt accounting moves to **pre-dispatch** so a 429'd or failed attempt
  consumes a slot, matching upstream accounting
  (`openrouterFreeWindow.ts:131-141`), and a lane cap that is set but not yet
  observed never parks the provider.
* **NEW header correction** (nothing in onegw reads these today): after every
  upstream response, fold in `x-ratelimit-limit`, `-remaining`, `-reset`, with
  `Retry-After` as a floor (`Math.max(headerReset, retryAfter)` —
  `openrouterFreeWindow.ts:158-218`). Server-declared limit beats the locally
  configured tier, always.
* **Preflight short-circuit**: lane exhausted ⇒ `503 free_lane_exhausted` +
  `Retry-After` before any network write, and `Fallbackable` so combos roll to
  the next leg. This is the case a USD-only quota API cannot see
  (`openrouterQuotaFetcher.ts:225-243`).
* **Account-vs-lane keying**: N gateway accounts on one upstream account share
  one window; `providers.free_lane_key` (default: account name, which is what a
  single-credential install has) collapses them explicitly
  (`openrouterFreeWindow.ts:14-19,90-97`).
* RPM: reuse `ratelimit.AllowRPM(key, rpm)` with the same key.

**Config:** per-provider, mirroring the existing quota block:

```toml
[[providers]]
name = "openrouter"
free_lane            = "auto"  # auto|on|off — auto = free lane for :free models
free_quota_window    = "daily" # UTC-day grid (quota.go), also "5h"/"48h" rolling
free_rpm             = 20      # rolling 60s window, not a fixed bucket
free_limit_requests  = 50
free_lane_key        = "openrouter-account-1"  # collapse keys onto one upstream account

[[free.boost]]        # deposit-unlock: reported, NEVER summed into the steady total
lane = "openrouter"
requests_per_day = 1000
note = "a one-time $10 lifetime top-up raises OpenRouter's free pool 50 -> 1000 req/day"
```

`free.boost` is the port of `FREE_TIER_BOOSTS` (`freeModelCatalog.ts:63-72`).
It stays out of the steady headline and is surfaced as a separate "unlock
more" figure, or the number is inflated — upstream pitfall #2.

Why the limits are configured + header-corrected rather than copied: the two
upstreams disagree with each other in their own prose. 9router's OpenRouter
registry notice claims "27+ free models, no credit card needed, 200 req/day.
After ... credit: 1,000 req/day" (`registry/openrouter.js:13`) while OmniRoute's
window service uses `DAILY_LIMIT_BASE = 50` / `DAILY_LIMIT_PURCHASED = 1000`
(`openrouterFreeWindow.ts:29-32`). onegw starts from the operator's number and
lets `x-ratelimit-limit` overwrite it from the live response: the vendor that
enforces the limit is the only one worth believing.

**Tests:** quota lane-key table tests; header-correction against captured
OpenRouter header sets; preflight returns 503 without dialing (assert via a
counting `httptest` server); failed-attempt-counts; reload `Inherit` keeps the
lane counters; boost never enters the steady sum.

**Commit:** `feat(quota): free-lane windows with x-ratelimit self-correction`

## Phase 4 — routing that cannot silently go paid

**Goal:** `auto:*:free` and task routing work on live evidence.

* **`auto:<task>:free`** resolved in `router.Resolve` (`router.go:267`):
  the combo-target pool, filtered to `free.Index.Free`, in task-score order
  (`task.go`). **Zero matches ⇒ empty target list ⇒ `503 no_free_lane`**, never
  a paid fallback (OmniRoute `virtualFactory.ts:656-701`; the legacy fallback is
  an env opt-in there — no fallback is the default here, and the config knob is
  the one-line addition of `free.allow_paid_fallback` if it is ever wanted).
  The same filter is applied to *every* combo under `hide_paid_models`, because
  a route that only the listing hid is a 402/403 waiting to happen
  (`paidModelFilter.ts:38-44`). Both upstreams also record what that filter
  does **not** cover — modality registries, operator combos and alias-backed
  rows are left unfiltered because they have no per-entry price to test
  (`catalog.ts:251-256`). onegw's narrower catalog (advertised ids + tiers)
  inherits a smaller version of that gap: embedding/stt/tts pass-through
  providers keep their models, and it is stated in the config comment rather
  than discovered in an incident.
* **Tier classifier**: `classifyTier(prov, model) → free|cheap|premium`,
  precedence = provider declared `free_lane=on` → provider override → model glob
  override → price thresholds (`tierResolver.ts:21-108`). In onegw the data
  source is `[[providers.tier]]` + the live index, so no new config kind. Free
  and pro tiers act as **filters**, not scoring bias
  (`suffixComposition.ts:75-93`) — matches onegw's existing "power gates
  ordering, never removes a target" discipline, with the free lane as the one
  hard exception.
* **Model-scoped drain**: on lane exhaustion park `(provider, model)`, not the
  account — siblings on the same credential stay eligible
  (`targetExhaustion.ts:185`, `freeTierCatalog` drain rule). onegw already owns
  this primitive (`BenchModel` + `ModelBenchTTL`); the change is making the
  free-lane park use the vendor's reset instant as TTL instead of the flat
  default, and self-heal on the next cycle — the
  `server/subquota.go:92 parkExhaustedSubscription` hook is the pattern to copy
  (cap one poll cycle so a recovered subscription un-parks itself).
* **classify429 parity**: split `rate_limit` from `quota_exhausted` in
  `APIError` — 429 alone never proves exhaustion, only an explicit pattern does
  (`classify429.ts:23-30,237-273`); a declared retry window `< 3600s` is a rate
  limit even when the text mentions a quota, because the long lockout overshoots
  the upstream reset by 60-360× (`classify429.ts:134-142`, their #9504). onegw
  already benches rate limits on the 10s→60s `[rotation]` ladder and
  model-scoped refusals on `model_bench_ttl` (default 5m); the port routes a
  `quota_exhausted` verdict to a new, longer `[rotation] quota_bench` (default
  1h, matching upstream's `cooldownByKind`), and keeps everything else on the
  shipped paths. Parse `Retry-After` in all three dialects — Groq relative
  (`5m`), plain integer seconds, HTTP-date — plus the
  `please retry in 38.92s` literal, in that order (`classify429.ts:185-319`; the
  order matters because `parseInt("5m") === 5`).
* **Per-provider 429 retry policy** (matrix #26): 9router's kiro sets
  `retry: {"429": 0}` — never retry a 429 in place, rotate immediately — beside
  per-model `rateMultiplier` and `quotaFamily` tags
  (`registry/kiro.js:26-28,71-73`). onegw's `[rotation]` (#84) is the owner of
  that shape; the addition is a `retry_after_n` knob per provider, not a new
  table.
* Config: `[free] hide_paid_models` gates combo resolution too (matrix row 14;
  one predicate, two call sites — listing and routing).

**Tests:** `auto:coding:free` never selects a paid leg (incl. the mixed case
that motivated upstream pitfall #10); empty-pool 503; model-scoped drain leaves
siblings; classify429 table over captured bodies + all three Retry-After
dialects.

**Commit:** `feat(router): auto:*:free lanes + quota-vs-rate 429 split`

## Phase 5 — telemetry, provider registry, keyless and probe lanes

**Goal:** the free capacity is measurable and one command reveals it.

* **subquota dialects** (registry + `Dialects()` single source already exist —
  `subquota.go:40-56`):
  * `openrouter-key` → `GET https://openrouter.ai/api/v1/key`:
    `limit`, `limit_remaining`, `limit_reset`, `is_free_tier`, `usage{,_daily,

## Phase 6 — statistics, Radar overlay, dashboard, docs

**Goal:** full parity on the numbers, honest about their provenance.

**Aggregation** (`free.Summarize`, OmniRoute math over live rows):
`RECURRING = {recurring-daily, recurring-monthly, keyless}`
(**`recurring-credit` is not recurring** — it goes into the credit sum;
`recurring-uncapped`, `one-time-initial`, `discontinued` never enter the
headline — `freeModelCatalog.ts:56`). `dedupedSum` takes **max per `poolKey`**
and sums loose `poolKey==""` entries, so a 30-model shared pool contributes one
budget, not thirty (`:80-95` — upstream pitfall #1). Outputs
`steady | steady+recurringCredits | firstMonth | boostMonthly |
uncappedProviders | modelCount | poolCount | headline`. Uncapped lanes are
**listed, never summed**: rate-limit-only free is theoretical capacity, not
granted (`freeTierCatalog.ts:4-7` — upstream pitfall #3; it names tencent,
siliconflow, nvidia, baidu, publicai and sparkdesk as that set). One-time
signup credits and discontinued tiers are excluded because they do not recur.
`curated_at` is a literal per provider (the *date this instance last verified
it*), never a file mtime — a rebuild rewrites mtimes and would call a months-old
catalog "fresh" (`freeModelCatalog.data.ts:12-18` — pitfall on staleness).

**Radar overlay** (`internal/free/radar.go`, opt-in, off by default): Ed25519
signature verified over the **exact wire bytes**, never re-serialized JSON
(`radar/verify.ts:1-9`); pinned SPKI key + `ONEGW_RADAR_PUBKEY` override for
forks (`pinnedKeys.ts:21-37`); `MAX_FEED_BYTES = 10 MiB` enforced twice
(Content-Length preflight **and** running stream total, so a lying header can't
bypass — `sync.ts:213-259`); 30s timeout; version floor `YYYY.MM.DD.n` strictly
newer (`sync.ts:111-122`); hourly scheduler tick, 24h catalog cadence, 6h
stale-on-read, all timers idle-safe. Merge semantics — add rows, field-override
rows, **never delete by absence**, but `enabled:false` from the feed always wins
(over a local `enabled:true` too) — `applyFeed.ts:191-330`. `poolKey`/`freeType`
mapping: `per_model|shared_pool → tokensPerMonth`, `rate_only → 0`,
`shared_pool.poolId → poolKey`, feed-derived `creditTokens` always 0
(`applyFeed.ts:138-150,351`). `go.mod` gains **zero** deps: `crypto/ed25519` +
`encoding/json` cover it; a hand-rolled subset validator replaces Zod, and the
schema is documented in the file header. Radar remains a *provider of free
metadata* — onegw is a consumer, and the gateway works with the flag off and
the network dead (last signed cache + live-derived index).

**Dashboard:** new page `free` (`navItems`, `internal/server/admin_pages.go:352`) +
`templates/free.html` + `GET /admin/api/v1/free/summary` → totals, per-pool
breakdown, ToS/privacy column, `used_this_month` (store rollup), `remaining`,
`catalog_curated_at`, `keyless_providers`, `?exclude_tos_avoid=1`, plus the
ranking view: providers ordered by measured tokens/sec × headroom (onegw's
`speed.go` EWMA + the quota tracker), which is the honest local substitute for
an externally-supplied Elo table.

**Drift CI** (`scripts/free_drift.sh`, replaces OmniRoute's
`check-nvidia-catalog-drift.ts` + `check-docs-counts-sync.mjs`): probes each
configured lane's `/models`, diffs against the stored catalog, exits non-zero on
drift, and asserts the counts quoted in README/docs match a fresh
`Summarize()` — *availability alone does not prove a model is free*
(`check-nvidia-catalog-drift.ts:76-97`). Wired into the existing release
workflow as a non-blocking job (it needs network + keys).

**Pitfalls carried into the code as comments** (all five upstream call them out
by number; the Go versions must keep them pinned or they come back): pool
duplication inflation, deposit-boost double count, rate×24/7 inflation, ToS
verdict is **advisory, not a routing gate** (`docs/reference/FREE_TIERS.md:64`
— `avoid` still routes; the flag only surfaces in the UI), and the privacy cost
of free (`trainsOnPrompts` must appear next to the quota, never hidden behind a

## Memory/perf contract (the 100 MB rule)

| Structure | Bound |
| --- | --- |
| `free.Index` | one entry per (provider, advertised model). Live OpenRouter is ~490 rows, a big relay's `/v1/models` is thousands; entries are ~120 B ⇒ < 1 MiB. Capped: 20 000 entries, oldest-evicted, `ponytail:` comment naming the ceiling. |
| Catalog artifacts | on disk under `data_dir`; the raw file is ~470 KB (9router trims 4.3 MB → 470 KB by keeping id/context/output/modality only — `catalogOverride.js:12-14`). Never mmap'd, read once at boot, mtime-invalidated. |
| Sync loops | 1 goroutine per source, `time.Timer` not tickers, no work when `[free] catalog_sync = ""` |
| Discovery | inherits `discoveryConcurrency = 3`, `discoveryTimeout = 15s`, 8 MiB response cap |
| Radar | opt-in; 10 MiB hard byte cap enforced twice; parsed into the existing `Index`, no second copy |
| Hot-path cost | `Index.Free(prov, model)` = one map probe under `RLock`; called once per request at dispatch and once at advertise time. Quota preflight = `ratelimit.AllowRPM` + 2 map reads. |

## Risks

1. **Numbers without provenance.** A measured budget is only as honest as its
   last verification; hence per-provider `curated_at` + the drift script. A
   `Summarize()` headline must always render with the date it was measured.
2. **Branch base.** Local `master` and `origin/master` have diverged, and the
   main checkout carries uncommitted work (cline OAuth etc.). This branch is on
   `origin/master` @ `d7cc35b` (which already has the discovery cache P1/P5
   extend); rebase and re-diff if the intended trunk turns out to be local
   `master`.
3. **Vendor drift.** models.dev and OpenRouter change the free lineup without
   notice; onegw's `openCodeFreeModels` comment already records upstream
   delisting ids with a 401. Mitigation: never advertise a live-derived model
   that has not been seen in 2 sync cycles, and quarantine it as
   `discontinued` rather than deleting it.
4. **Parked-forever classes.** The 429-vs-quota split must not park a lane for
   an hour on a soft rate limit; the <3600s rule + lane-scoped (not
   account-scoped) parks are the guards.
5. **Radar is one vendor's server.** Default off, unverifiable ⇒ ignored, and
   the gateway must be no worse without it.
6. **Aliyun console path** deliberately unported (§Phase 5) pending an explicit
   operator decision about browser-session credential handling.
